What is an XML sitemap?

An XML sitemap is a structured list of URLs for a site, created specifically to help search engines discover and prioritize pages for crawling — especially useful for large sites, new sites, or sites with many pages that have few internal links pointing to them. A sitemap can be of type urlset (a direct list of URLs, each optionally with a last modification date, estimated change frequency, and relative priority) or sitemapindex (an "index of indexes," pointing to other sitemap files — used when a site has more URLs than fit in a single file). This tool fetches the sitemap at the default location (/sitemap.xml) and automatically identifies which of the two formats is being used.

How to interpret the result

The number of declared URLs gives a quick idea of the site's size from an SEO perspective. The sitemap protocols establish technical limits of 50,000 URLs and 50 MB uncompressed per file — sites exceeding these limits should split the URLs across multiple sitemap files referenced by a sitemap index; this tool alerts when these limits are exceeded. The absence of the lastmod field in an entry does not invalidate the sitemap, but reduces search engines' ability to correctly prioritize what needs re-crawling. A sitemap of type sitemapindex is normal for large sites; if you expected to see individual URLs and received an index, that is expected — the index points to the actual files.

Common use cases

This tool is used to confirm that the sitemap is accessible and well-formed before submitting it to Google Search Console or Bing Webmaster Tools, to quickly audit how many URLs a competing site declares publicly, and to diagnose indexing problems when a sitemap is returning an error or exceeding the sitemap protocol's technical limits. Development teams also use it to validate that automatic sitemap generation (common in CMSs and frameworks) is working correctly after a deploy.

Limitations

For security, the parser rejects sitemaps that contain custom DOCTYPE or ENTITY declarations, a protection against malicious XML attacks — legitimate sitemaps never need these declarations, so this should not affect files generated normally. This tool checks only the standard path /sitemap.xml; if your site declares the sitemap at another URL (common, and perfectly valid), configure it directly in Google Search Console even if this check does not find it automatically.

Sitemap is not robots.txt

It is common to confuse the roles of the sitemap and robots.txt, but they are complementary and opposite in function: robots.txt tells what not to crawl, while the sitemap actively suggests what should be discovered and considered for indexing. Having a URL listed in the sitemap does not guarantee it will be indexed — the sitemap is just an invitation, and search engines still apply their own quality and relevance criteria before deciding to index each page. On the other hand, it is contradictory and wastes crawl budget to include in the sitemap URLs that are blocked in robots.txt or marked with noindex — in these cases, the correct signal is to remove the URL from the sitemap as well, keeping both files consistent with each other.
