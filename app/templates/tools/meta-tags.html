What are title and meta tags?

The <title> tag and meta description are the two most visible elements of a page in search results: the title becomes the clickable blue link, and the description typically appears as the summary below it. Together with the canonical (which informs the "official" version of a URL when duplicates exist), the meta robots (which controls whether the page can be indexed and followed), and the Open Graph/Twitter Card tags (which control how the link appears when shared on social networks), these elements form the foundation of on-page SEO for any page. This tool fetches the provided page and extracts all these elements at once, along with an H1 headings summary and approximate word count.

How to interpret the result

The recommended range for the title is 30 to 60 characters — below that, the title may not use all the available space in search results; above, it risks being truncated with ellipsis. For the meta description, the recommended range is 70 to 160 characters. These ranges are not strict Google rules but practical approximations widely used by the SEO industry to avoid visual truncation. A missing canonical is not necessarily an error — simple pages without risk of duplication can do without it — but on sites with URL parameters, pagination, or duplicate HTTP/HTTPS, the absence of canonical can cause relevance dilution between versions of the same page. More than one H1 tag per page is technically allowed by HTML5, but the recommended SEO practice is still to use only one H1 per page, representing the main topic of the content.

Common use cases

SEO professionals use this tool before publishing a new page, to check that all essential elements have been correctly filled in by the CMS or the content team. It is also useful for quickly auditing competitor pages, for debugging why a link shared on WhatsApp or LinkedIn is not showing the expected image/title (checking Open Graph tags), and for identifying pages with missing title or description in a quick manual survey before a more comprehensive crawling audit.

Limitations

This tool reads the HTML returned directly by the server, without executing JavaScript — sites that build the title, meta tags, or content via JavaScript in the browser (client-side rendering without pre-rendering) may not reflect correctly here, as search engines also have variable behavior in processing this type of content. The word count is approximate, based on visible text extracted from raw HTML, without differentiating main content from menus, footers, and other navigation elements.

Title, description, and click-through rate

Beyond influencing perceived relevance to search engines, title and meta description directly affect the click-through rate (CTR) in search results — they are, in practice, the advertisement for your page. A generic title like "Home page" or one repeated across multiple pages of the same site wastes a valuable differentiation opportunity; the ideal is for each page to have a unique title that specifically describes the content of that URL. The meta description, even though it is not a direct ranking factor according to Google itself, functions as a "sales text" that can significantly increase clicks when well written, including a clear call to action for what the user will find. It is also worth remembering that search engines may, at their own discretion, replace the declared description with a snippet extracted from the page's content when they judge it more relevant for the user's specific search.
