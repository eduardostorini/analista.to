O que são title e meta tags?

A tag <title> e a meta description são os dois elementos mais visíveis de uma página nos resultados de busca: o title vira o link clicável azul, e a description normalmente aparece como o resumo abaixo dele. Junto com o canonical (que informa qual é a versão "oficial" de uma URL quando existem duplicatas), o meta robots (que controla se a página pode ser indexada e seguida) e as tags Open Graph/Twitter Card (que controlam como o link aparece ao ser compartilhado em redes sociais), esses elementos formam a base do SEO on-page de qualquer página. Esta ferramenta busca a página informada e extrai todos esses elementos de uma vez, junto com um resumo de headings H1 e contagem aproximada de palavras.

Como interpretar o resultado

A faixa recomendada para o title é de 30 a 60 caracteres — abaixo disso, o título pode não aproveitar todo o espaço disponível nos resultados de busca; acima, corre risco de ser cortado com reticências. Para a meta description, a faixa recomendada é de 70 a 160 caracteres. Essas faixas não são regras rígidas do Google, mas aproximações práticas amplamente usadas pela indústria de SEO para evitar truncamento visual. O canonical ausente não é necessariamente um erro — páginas simples sem risco de duplicação podem prescindir dele — mas em sites com parâmetros de URL, paginação ou HTTP/HTTPS duplicados, a ausência de canonical pode causar diluição de relevância entre versões da mesma página. Mais de uma tag H1 na página é tecnicamente permitido pelo HTML5, mas a prática recomendada de SEO ainda é usar apenas uma H1 por página, representando o tópico principal do conteúdo.

Casos de uso comuns

Profissionais de SEO usam esta ferramenta antes de publicar uma página nova, para conferir se todos os elementos essenciais foram preenchidos corretamente pelo CMS ou pelo time de conteúdo. Também é útil para auditar rapidamente páginas de concorrentes, para depurar por que um link compartilhado no WhatsApp ou LinkedIn não está mostrando a imagem/título esperados (checando as tags Open Graph), e para identificar páginas com title ou description ausentes em um levantamento manual rápido antes de uma auditoria mais completa com ferramentas de rastreamento.

Limitações

Esta ferramenta lê o HTML retornado diretamente pelo servidor, sem executar JavaScript — sites que montam o title, meta tags ou conteúdo via JavaScript no navegador (client-side rendering sem pré-renderização) podem não refletir corretamente aqui, já que os buscadores também têm comportamento variável ao processar esse tipo de conteúdo. A contagem de palavras é aproximada, baseada no texto visível extraído do HTML bruto, sem diferenciar conteúdo principal de menus, rodapé e outros elementos de navegação.

Título, description e a taxa de cliques

Além de influenciar a relevância percebida pelos buscadores, title e meta description afetam diretamente a taxa de cliques (CTR) nos resultados de busca — eles são, na prática, o anúncio da sua página. Um title genérico como "Página inicial" ou repetido em várias páginas do mesmo site desperdiça uma oportunidade valiosa de diferenciação; o ideal é que cada página tenha um title único, que descreva especificamente o conteúdo daquela URL. A meta description, mesmo não sendo um fator direto de ranqueamento segundo o próprio Google, funciona como um "texto de venda" que pode aumentar significativamente os cliques quando bem escrita, incluindo uma chamada clara para o que o usuário vai encontrar. Vale lembrar que buscadores podem, a critério próprio, substituir a description declarada por um trecho extraído do conteúdo da página quando julgarem mais relevante para a busca específica do usuário.
